# Dynamic English School

Public-facing school website built with Next.js App Router, JavaScript, Tailwind CSS, Motion, and Lucide.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

School content and replaceable image paths are centralized in `data/school.js`. Placeholder artwork lives in `public/images/placeholders/`.
